# 数据库填充脚本说明

## 功能

`seed_data.go` 脚本用于填充MongoDB数据库的测试数据，包括：

1. **健康管家** - 3个健康管家
2. **护理级别** - 3个护理级别（一级、二级、三级）
3. **膳食计划** - 3个膳食计划（普通餐、低糖餐、流质餐）
4. **房间** - 5个房间（单人间、双人间、多人间）
5. **床位** - 根据房间容量自动创建床位
6. **用户** - 5个注册用户
7. **客户** - 5个客户（4个已入住，1个未入住）
8. **服务项目** - 5个服务项目
9. **客户服务** - 4条客户购买服务记录
10. **登记记录** - 5条登记记录（入住、外出）

## 使用方法

### 方法1: 直接运行（推荐）

```bash
cd scripts
go run seed_data.go
```

### 方法2: 编译后运行

```bash
cd scripts
go build -o seed_data seed_data.go
./seed_data  # Linux/Mac
# 或
seed_data.exe  # Windows
```

## 注意事项

1. **数据覆盖**：脚本会直接插入数据，如果集合中已有数据，会继续追加。如果需要清空后重新填充，可以取消注释脚本中的清空代码。

2. **密码加密**：所有用户密码使用bcrypt加密，默认密码是 `123456`。

3. **关联关系**：脚本会自动建立数据之间的关联关系：
   - 客户关联用户、床位、膳食计划、护理级别、健康管家
   - 床位关联房间和客户
   - 客户服务关联客户和服务项目
   - 登记记录关联客户

4. **时间戳**：所有记录都包含 `created_at` 和 `updated_at` 时间戳。

## 故障排除

如果运行失败，请检查：

1. MongoDB服务是否运行
2. 数据库连接字符串是否正确
3. 网络连接是否正常
4. 是否有足够的数据库权限

## 自定义数据

如果需要修改填充的数据，编辑 `scripts/seed_data.go` 文件中对应的数据数组即可。
